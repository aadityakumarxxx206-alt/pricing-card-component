# Responsive Pricing Card Component

A modern and responsive **Pricing Card UI Component** that I built using clean HTML5 and custom CSS3. 

This project was a great hands-on exercise for me to master complex CSS layouts, positioning, and visual UI design.

## 🚀 Key Features
* **Flexbox Layout:** Ensures all three pricing cards align cleanly across different screen sizes.
* **Custom Header Shapes:** Uses CSS `clip-path` (ellipse) to give the card headers a unique curved aesthetic.
* **Elevated Featured Card:** Highlights the middle "Standard" plan using CSS `transform` and scale effects to capture user attention.
* **Visual Styling:** Includes modern `box-shadow` glow effects and styled FontAwesome check/cross icons for plan features.

## 🛠️ Tech Stack & Tools
* **HTML5** (Semantic structure)
* **CSS3** (Flexbox, Clip-Path, Positioning, Box-Shadow)
* **FontAwesome Icons**
* **Git & GitHub** (Version control)

## 📌 What I Learned
Through building this project, I deepened my understanding of:
1. Proper HTML nesting to prevent broken Flexbox layouts.
2. Avoiding unnecessary `position: absolute` styling on container cards to maintain natural document flow.
3. Structuring clean CSS for reusable components.
